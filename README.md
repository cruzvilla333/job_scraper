Build instructions:

Node, NPM and NVM set up, skip if already installed:

  1. Install nvm,
    Mac - curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.3/install.sh | bash , then run "source ~/.bashrc"  or "source ~/.zshrc" depending on your shell.
    Windows - Go to "https://github.com/coreybutler/nvm-windows/releases". Download the latest nvm-setup.zip file. Extract and run the installer (nvm-setup.exe). Verify nvm version by running "nvm -v"
  2. Install node js by runninng "nvm install v23.5.0", verify node version by running "node -v".
  3. Install npm by running "npm install -g npm@10.9.2", verify npm version by running "npm -v".


Project build instructions:

  1. clone project.
  2. run "npm install".
